# Nuyen Sub

Web tự tạo phụ đề cho video, chạy 100% trong trình duyệt (không cần server, không cần API key, video không bị tải lên đâu).

## Cách dùng
1. Mở `index.html` bằng Chrome/Edge (bật GitHub Pages hoặc tải file về máy rồi mở).
2. Kéo thả video vào.
3. Bấm **Tạo phụ đề**: AI Whisper nghe và ghi lời (lần đầu tải mô hình ~80 MB, các lần sau dùng lại).
4. Sửa câu chữ / thời gian ở danh sách bên phải, chỉnh font, cỡ chữ, màu, vị trí.
5. **Xuất video có phụ đề** (chữ in thẳng vào video) hoặc tải file `.srt` / `.vtt`.

Có thể nhập sẵn file `.srt`/`.vtt` thay vì tạo bằng AI.
