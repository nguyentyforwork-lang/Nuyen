# KPI App Ecomdy

Dashboard ROAS/KPI theo app. Mở `index.html` hoặc bật GitHub Pages (Settings → Pages → Deploy from a branch → chọn nhánh, thư mục `/ (root)`).

Dữ liệu nhập trên trang được lưu trong trình duyệt (localStorage). Dùng **Xuất JSON** / **Nhập JSON** để sao lưu hoặc chuyển sang máy khác.
