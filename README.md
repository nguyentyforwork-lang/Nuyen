# Nuyen — Tính Cashback Quý

Mở `index.html` bằng trình duyệt (không cần cài đặt, cần mạng để tải thư viện đọc Excel).

1. **Chính sách**: sửa tier, tỷ lệ % theo khu vực, danh sách quốc gia mỗi khu vực. Chính sách được lưu lại trên trình duyệt.
2. **Dữ liệu**: tải một hoặc nhiều file `.xlsx/.csv` (cột Account ID, Account name, Country/Region, Cost, Tên khách, Entity). Cột được tự nhận, có thể chỉnh lại.
3. **Kết quả**: cashback theo Khách hàng → Entity → Account, xuất Excel hoặc sao chép để dán vào Google Sheets.
